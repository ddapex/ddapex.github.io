Политика конфиденциальности

Последнее обновление: 2026

1. Где обрабатываются данные

Auto-Video работает полностью на компьютере пользователя. Видео, аудио, субтитры и настройки не отправляются автору приложения и не загружаются ни на какие серверы. Анализ, нарезка и рендер выполняются локально.

2. Что хранится на диске

  • Настройки приложения — %APPDATA%\AutoVideo\config.json.
  • Токены TikTok — %APPDATA%\AutoVideo\tiktok.json.
  • Логи — %APPDATA%\AutoVideo\logs\, ротация, только техническая информация.
  • Временные файлы рендера — удаляются после завершения.

3. Что уходит в TikTok

Только по вашему действию: видеофайл, выбранное описание с хештегами и уровень приватности. Передача идёт напрямую с вашего компьютера на серверы TikTok по API Content Posting. Обработка этих данных на стороне TikTok регулируется его собственной политикой.

4. Аналитика

Приложение не содержит телеметрии, счётчиков, рекламных SDK и не собирает статистику использования.

5. Удаление данных

Удалите папку %APPDATA%\AutoVideo — настройки, логи и токены будут стёрты. Отозвать доступ приложения к аккаунту можно в настройках безопасности TikTok.

6. Дети

Приложение не предназначено для лиц младше 13 лет и не собирает данные о них.
