Desktop tool

Auto-Video

Локальное приложение для Windows: находит хайлайты в записанном видео, режет их, добавляет субтитры и музыку, экспортирует вертикальные ролики и отправляет готовый файл в собственный аккаунт TikTok как черновик.

Как это работает

  • Видео обрабатывается на компьютере пользователя, в облако ничего не уходит.
  • Авторизация TikTok идёт по официальному OAuth 2.0 (Login Kit).
  • Публикация использует Content Posting API: файл попадает в черновики аккаунта.
